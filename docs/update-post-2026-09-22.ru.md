# Orchestra: надёжнее работа с изображениями и локальными агентами

Выпускаем Orchestra Runtime 0.5.0 и готовим обновление агентного режима Operium Desktop. Главный фокус — локальные модели: корректно передавать изображения, бережнее расходовать контекст и не принимать оборванный ответ за выполненную задачу.

**Изображения доходят до модели.** Исправили ошибку на границе с llama.cpp: при подготовке запроса терялись маркеры изображений. Добавили проверки обычного и потокового ответа на реальной VLM.

**Текстовая модель получает описание, а не притворяется зрячей.** В новой реализации Desktop можно выбрать VLM либо разрешить локальный анализ изображения. Перед передачей описания основной модели пользователь просматривает и подтверждает его. Если основная модель облачная, ей передаётся одобренное описание, а не исходное изображение.

**Меньше незаметных сбоев в агентном цикле.** Аргументы инструментов проверяются по схеме до выполнения. Повреждённые и незавершённые вызовы не запускаются. Контекст оценивается перед каждым раундом: старые завершённые ходы можно убрать, а текущую задачу и результаты её инструментов нельзя молча обрезать.

**Размышления отделены от ответа.** Локальный анализатор собирает описание только из видимого content. Для проверенного профиля Qwen3.5 автоматически отключаем thinking на этапе описания; для остальных моделей сохраняем настройки провайдера. Расширенные настройки остаются доступны.

Проверили Runtime и Ollama на одном Qwen3.5-9B GGUF, одном проекторе, одинаковом контексте и наборе инструментов. По три прогона каждого сервера — оба сценария прошли во всех запусках. Также прошли 74 автоматических теста агентного слоя Desktop и Go-проверки Runtime.

Это не обещание безошибочной работы любой модели: пока проверено одно простое изображение. Сложные скриншоты, мелкий текст и другие VLM — следующий этап. Точный подсчёт vision-токенов и отдельное хранилище вложений также ещё впереди.

Runtime: https://github.com/IlyaAbramychev/orchestra-runtime/releases/tag/v0.5.0

Важно: изменения Desktop пока подготовлены в рабочей ветке. Подписанный и нотарифицированный установщик Desktop ещё не выпущен; обновление Runtime само по себе не добавляет новый интерфейс в установленное приложение. VS Code-плагин этим релизом не обновляется.
